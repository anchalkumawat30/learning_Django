# Django Learning 📚

## About This Repository

This repository documents my journey of learning Django from beginner level.

## 🎯 Learning Goals

* Understand Django fundamentals and MVT architecture.
* Learn URL routing, views, templates, and models.
* Connect Django with PostgreSQL.
* Perform CRUD operations using Django ORM.
* Implement authentication, authorization, and role-based access control.
* Learn Django REST Framework (DRF) and API development.
* Understand testing, debugging, and security.
* Learn deployment using AWS and related technologies.
* Build practical projects to strengthen my skills.

## 📚 Learning Roadmap

### Beginner Level

* Introduction to Django
* Django installation and virtual environments
* Project and application structure
* URLs, views, and HTTP requests/responses
* Templates and static files
* MVT architecture
* Models and Django ORM
* PostgreSQL integration
* Migrations and Django Admin
* Forms and validation
* CRUD operations

## 🎯 Final Goal

To develop a strong understanding of Django and build secure, maintainable, and practical web application
